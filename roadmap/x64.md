# x86-64

Plan, no code. 2026-10-17.

Today only 32-bit PE images run; the loader refuses any other machine.

- **cork-x64:** a REX decoder, 64-bit registers and addresses, on cork's executor contract
  (`bits: 64` in `core/src/layers/cpu/engine.js`).
- **Loader:** PE32+, 64-bit system DLLs and trap stubs.
- **Bridge:** the x64 convention (RCX, RDX, R8, R9, shadow space); COM tables of 8-byte slots.
- **Win32:** the 64-bit layout of every structure a handler reads or writes — the largest part.
- **Exceptions:** table-based SEH (`.pdata`, `.xdata`).
- **WOW64:** 32- and 64-bit processes side by side; `SysWOW64`, `Wow6432Node`.
- **Address space:** a 4 GiB window works in every browser; `memory64` is not in stable Safari.

First goal: a console x64 program from start to exit.
