# OpenGL 2.0 to 4.x

Plan, no code. 2026-10-17.

Today: OpenGL 1.1 with extensions — multitexture, cube maps, S3TC, vertex buffer objects, ARB
assembly programs. No GLSL.

- **2.0:** GLSL to WGSL.
- **3.x:** framebuffer, vertex array and uniform buffer objects; the core profile;
  `wglCreateContextAttribsARB`.
- **4.x:** WebGPU has no geometry or tessellation shaders; they are emulated in compute.
