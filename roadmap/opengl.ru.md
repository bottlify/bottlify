# OpenGL 2.0–4.x

План, кода нет. 17 октября 2026.

Сейчас: OpenGL 1.1 с расширениями — мультитекстуры, cube maps, S3TC, буферы вершин, ассемблерные
программы ARB. GLSL нет.

- **2.0:** GLSL в WGSL.
- **3.x:** объекты кадрового буфера, массивов вершин и буферов uniform; core profile;
  `wglCreateContextAttribsARB`.
- **4.x:** в WebGPU нет геометрических шейдеров и тесселяции; они эмулируются через compute.
