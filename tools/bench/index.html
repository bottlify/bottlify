Cork stand

cork's micro workloads, 32-bit and x86-64, on the guest's own clock: every device translates and runs the same code. Work must read as recorded on every device; MIPS is this device's speed. With two builds, B / A is the second's speed against the first's, the median over the runs with the lowest and highest run beside it: green or red only where every run agrees. A whole run can land a few per cent apart from another when the browser optimises the code otherwise, so compare over several runs.

Press Run: one run of both widths takes about a minute a build on a laptop.
