Cork stand

cork's micro workloads (32-bit and x86-64) on the guest's own clock: every device translates and runs the same code, so the work column must read as recorded everywhere, and MIPS is this device's speed. Noise is how far the rounds of one workload part in this run: a difference inside it is not one this device can show. A whole run can land elsewhere when the browser happens to optimise the code otherwise, so compare devices or builds over several runs.
